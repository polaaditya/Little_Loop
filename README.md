# LittleLoop

Small moments. Stronger families.

LittleLoop is a warm, minimal family connection landing page and demo dashboard for working parents, stay-at-home parents, caregivers, infants, kids, teenagers, and siblings.

## Solution

Busy families often miss small chances to connect during work, school, and caregiving routines. LittleLoop helps families build closeness through tiny daily rituals:

- Care Steps that track meaningful connection without pressure
- Gentle Connection Streaks that celebrate consistency
- Age-aware prompts for infants, little kids, big kids, and teens
- Sibling Loops for kindness notes and shared memories
- Memory Jar for voice notes, photos, answers, and tiny wins
- Family Circle for parents, caregivers, grandparents, and siblings

## MVP

This MVP is a static landing page with a frontend dashboard preview and sample user database rendered from JavaScript.

Run locally:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```
